🎯 渗透实战作战任务:
作为白帽子，你获得了授权对目标企业 corp-security.com 进行黑盒资产测绘。
企业主站启用了云加速 CDN 与高防 WAF，但开发人员在某个内部子域名上疏忽遗留了源码备份与敏感配置文件。
通关流程: 1. 枚举企业子域名并识别真实源站 IP ➔ 2. 使用目录扫描工具探测敏感泄露文件 ➔ 3. 读取配置文件提取数据库凭证与 Flag！
第 1 步 🌐 企业主域名资产与隐蔽子域名测绘 (Subdomain Recon)

输入目标企业主域名（如 corp-security.com），执行 DNS 解析、证书透明度日志 (CT Logs) 与字典碰撞，探测隐蔽子域名资产。

第 2 步 📁 目标资产敏感目录与源码泄露深度探测 (Dirsearch / Fuzz)

选择在第 1 步中发现的隐蔽子域名或源站资产，探测是否存在常见敏感文件（如 robots.txt、.git/config、.env、/api/v2/config.bak、swagger-ui.html）。
